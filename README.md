# Cosmetic E-Commerce Store

A dynamic and fully functional cosmetic e-commerce website with modern UI, responsive design, authentication system, shopping cart, product management, and admin dashboard built using HTML, CSS, Bootstrap, JavaScript, PHP, and MySQL.

---

## Features

- Admin Login System
- Dynamic Product Display
- Shopping Cart System
- Product Management (CRUD)
- Order Management
- Responsive UI
- Session Handling
- Database Integration

---

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript
- PHP
- MySQL

---

## Installation

1. Clone the repository
```bash
git clone https://github.com/Qanu91/cosmetic-ecommerce-store.git
```

2. Move project to XAMPP `htdocs`

3. Import `shop.sql` in phpMyAdmin

4. Start Apache & MySQL

5. Open in browser:
```
http://localhost/e-commerce
```
